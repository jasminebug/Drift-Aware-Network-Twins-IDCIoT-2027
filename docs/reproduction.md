# Reproduction protocol and present limits

## Standalone executable scope

The complete compact diagnostic pipeline is included in this archive. It includes log-PCA demand reduction, a conditional LSTM with an energy-score objective, a drift-aware reference, heuristic routing search, and lightweight PPO sanity testing. The included `run_reproduction.py --mode quick` is a **diagnostic smoke test**, not an exact reproduction of all reported results.

The paper compares MSE-only, adversarial-only, MSE+adversarial, MSE+energy-score, and MSE+adversarial+energy-score variants, and multiple DRL controllers. The included `src/gnt_repro/experiment.py` does **not** execute that entire ablation or full DRL evaluation as described in the paper. The attached manuscript-reported tables must therefore not be relabelled as generated by this code.

## Reproduce what the current code implements

```bash
python -m pip install -r requirements.txt
python run_reproduction.py --mode quick --output-dir outputs/quick_local
python -m pytest -q
```

For a longer run, the repository also exposes:

```bash
python run_reproduction.py --mode paper --output-dir outputs/paper_local --seed 7
```

**Caution:** `--mode paper` refers to the repository's longer configuration. Its existence is not proof that it matches every setting or experiment in the accepted paper. Do not replace manuscript data with this run's values without establishing experimental equivalence.

## Regenerate manuscript-table visualizations only

```bash
python scripts/check_manuscript_alignment.py
python scripts/plot_reported_tables.py
```

These commands validate reported table arithmetic and rebuild a figure from those tables. Neither command generates new experimental evidence.

## Protocol declared in the accepted manuscript

- NSFNET topology: 14 nodes and 42 directed links.
- Synthetic origin-destination traffic with an in-distribution scenario and S1 through S5.
- Reported 40 independent training weeks; the final text does not identify all validation/DRL trace sizes.
- Reported 400 control intervals per evaluation scenario.
- Forecast metrics use 100 rollouts; controller reference construction uses eight rollouts, resulting in a two-member empirical tail.
- Comparative ablations are single-seed; uncertainty of small differences is not quantified.

Keep the actual full study experiment code, seeds, validation partitions, parameter logs, hardware/software manifest, checkpoints, and scenario definitions before claiming exact numerical reproduction.

## Identified consistency gaps to resolve

1. In the paper, S5 is a **dual-link failure**. In current source `src/gnt_repro/traffic.py`, S5 applies only a mild demand multiplier; it does not directly remove topology links.
2. The paper describes a wider multi-variant GAN and PPO evaluation than is run in included `experiment.py`.
3. The compact quick-run configuration uses 4 training weeks and a 48-step test trace, whereas the manuscript describes longer experiments. No quick-run scores are shipped as manuscript evidence; outputs must be generated separately by future developers.
4. The paper's Table III has missing header/numerical cells. `paper/reported/table_iii_as_printed.csv` preserves these blanks.
5. The quantitative basis of manuscript Figure 3 is not available as a separate experiment trace. The manuscript image cannot establish a reproducible row-by-row numeric dataset.

Do not silently edit reported metrics or infer missing experimental observations from illustrations. The right fix is to retrieve or rerun the original experiments and attach their actual output with configuration and commit hashes.
